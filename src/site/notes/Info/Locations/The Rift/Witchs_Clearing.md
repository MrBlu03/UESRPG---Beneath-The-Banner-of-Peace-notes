# Witch's Clearing

## Description
A foul, feather-strewn clearing deep in the woods where a sinister hagraven made her lair.

## Features
- Totems of woven twigs, bird feathers, and animal skulls.
- A bubbling cauldron filled with vile dark concoctions.
