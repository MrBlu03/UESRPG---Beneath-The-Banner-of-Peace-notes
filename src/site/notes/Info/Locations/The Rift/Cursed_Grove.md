# Cursed Grove

## Description
A sinister, corrupted clearing located in the heart of the [[Info/Locations/The Rift/Northern_Forest\|Northern_Forest]], where the veil between the mortal world and the supernatural thinned.

## Features
- Bleeding trees with sap resembling dark crimson blood.
- A central ritual stone circle where [[Info/Characters/NPCs/Torik\|Torik]] performed the Old Nordic summoning chant.
