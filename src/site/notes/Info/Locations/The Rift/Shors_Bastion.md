# Shor's Bastion

## Description
A fortified redoubt and outpost protecting iron mining operations in the foothills of the Velothi Mountains.

## Features
- Stockade walls built against natural rock faces.
- Iron ore smelters and guard quarters.

## NPCs
- Miners
- Guards
