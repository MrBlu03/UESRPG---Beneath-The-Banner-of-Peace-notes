# The Ragged Flagon

## Description
A notoriously damp, subterranean tavern situated in the heart of the [[Info/Locations/The Rift/Riften\|Riften]] Ratway, built around a sunken reservoir.

## Features
- Wooden walkways suspended over murky green water.
- Flickering torchlight illuminating rough-hewn stone booths where clandestine contracts are sealed.
