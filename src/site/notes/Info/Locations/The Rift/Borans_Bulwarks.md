# Boran's Bulwarks

## Description
A specialized heavy armory and shield-making shop in [[Info/Locations/The Rift/Riften\|Riften]] owned and operated by the veteran Nord armorer [[Info/Characters/NPCs/Boran\|Boran]].

## Features
- Heavy anvils dedicated to shaping plate armor and reinforced kite shields.
- Display of custom bossed roundshields and reinforced tower shields.
