# Treva's Bend

## Description
A low-lying fishing village nestled along a bend in the river southwest of [[Info/Locations/The Rift/Riften\|Riften]]. Highly dependent on seasonal river fish runs.

## Features
- Wooden docks, drying racks for fishing nets, and smokehouses.
- Muddy thoroughfares and modest thatched-roof timber cottages.
