# Ysmir's Hall

## Description
An alternate regional reference and auxiliary shrine to the [[Info/Locations/The Rift/Hall_of_Ysmir\|Hall_of_Ysmir]], preserving the sacred traditions of Nordic warrior-kings.

## Features
- Runed pillars and votive weapon offerings dedicated to [[Info/Lore/Shor\|Shor]] and Ysmir.

## NPCs
- Nord Devotees

## Notes
- **[[2 -  Sessions/Session 008\|Session 008]]**: Mentioned in connection with regional temple registries in the Rift.
