# Ayr

## Basic Information
**Type:** City  
**Region:** Unknown (likely High Rock or Summerset)  
**Status:** Active  
**Significance:** Location of the [[Info/Organizations/Mages_Guild\|Mages Guild]] main guild hall

## Description
Ayr is the location of the main [[Info/Organizations/Mages_Guild\|Mages Guild]] guild hall, where dangerous magical artifacts are transported for permanent safe storage. The facility presumably has extensive wards and containment measures for Daedric and other hazardous items.

## Key Features
- **Mages Guild Main Hall**: Primary headquarters for artifact storage and research
- **Artifact Storage**: Secure containment for dangerous magical items
- **Anti-Magic Wards**: Advanced magical protections
