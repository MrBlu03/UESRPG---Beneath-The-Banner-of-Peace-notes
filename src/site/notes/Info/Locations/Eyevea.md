# Eyevea

## Basic Information
**Type:** Island / Pocket Dimension  
**Region:** Associated with Summerset (exists outside normal Tamriel)  
**Status:** Active  
**Significance:** Location of the [[Info/Organizations/Mages_Guild\|Mages Guild]] main guild hall for artifact storage

## Description
Eyevea is the location of the main [[Info/Organizations/Mages_Guild\|Mages Guild]] guild hall, where dangerous magical artifacts are transported for permanent safe storage. The facility has extensive wards and containment measures for Daedric and other hazardous items. The island was famously recovered by [[Arch-Mage Vanus Galerion\|Vanus]] and serves as a secure repository for items too dangerous to remain in Tamriel proper.

## Key Features
- **Mages Guild Main Hall**: Primary headquarters for artifact storage and research
- **Artifact Storage**: Secure containment for dangerous magical items
- **Anti-Daedric Wards**: Advanced magical protections specifically designed to contain Daedric artifacts
- **Isolated Location**: The island's unique nature provides additional security
