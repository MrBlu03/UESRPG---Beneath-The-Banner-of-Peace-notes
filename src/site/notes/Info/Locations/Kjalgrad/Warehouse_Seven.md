# Warehouse Seven

## Description
Warehouse Seven is a large, unassuming commercial storage building situated on the waterfront within the [[Info/Locations/Kjalgrad/Kjalgrad_Warehouse_District\|Kjalgrad_Warehouse_District]]. Despite carrying official [[Info/Organizations/Guilds/Guild_of_the_Silverroad\|Guild_of_the_Silverroad]] placards, it was secretly repurposed as a covert staging facility and security checkpoint for the [[Info/Organizations/Cults/Cult_of_Clavicus_Vile\|Cult_of_Clavicus_Vile]].

## Features
- **Heavy Reinforced Timber Doors**: Barred with reinforced iron locks and protected by enchanted warding runes.
- **Internal Storage Crates**: Stacks of legitimate timber, dried fish, and furs masking illicit contraband beneath false bottoms.
- **Trapdoor Sluice**: Hidden entrance leading down into the [[Info/Locations/Kjalgrad/Kjalgrad_Sewers\|Kjalgrad_Sewers]].

## NPCs
- **[[Info/Characters/NPCs/The_Scathing\|The_Scathing]]**: Horned Daedric manager stationed at the loading bay.
- **[[Info/Organizations/Guilds/Guild_of_the_Silverroad\|Caravan_Master]]**: Trade overseer managing incoming shipments.
- **Warehouse Guards**: Hired mercenaries guarding the premises.
